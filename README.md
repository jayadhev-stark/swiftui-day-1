# Day 1 - SwiftUI Learning

## About This Project
This project is part of my 5-day SwiftUI learning journey. On Day 1, I practised Swift programming fundamentals and learned how to display information using SwiftUI.

## Topics Covered
- Variables using `var`
- Constants using `let`
- Data types: `Int`, `Double`, `String`, and `Bool`
- Arithmetic operators
- Conditional statements (`if-else`)
- Loops and number ranges
- SwiftUI views such as `Text`, `VStack`, and `HStack`
- Basic styling, padding, and dividers

## Technologies Used
- **Language:** Swift
- **UI Framework:** SwiftUI
- **Code Editor:** MiniSwift Studio
- **Version Control:** Git and GitHub

## Project Features
- Displays basic student information
- Demonstrates Swift variables and constants
- Performs simple arithmetic calculations
- Checks whether a student has passed or failed
- Displays numbers from 1 to 5
- Uses SwiftUI components to create a simple interface

## Learning Outcome
I learned the basic syntax of Swift and how it compares with Java. I also practised building a simple user interface using SwiftUI components.

## How to Run
1. Open the project code in MiniSwift Studio.
2. Paste the SwiftUI code into the editor.
3. Click **Run** to execute the program.
4. View the interface in the preview.

## Code Example

```swift
let marks = 85

if marks >= 40 {
    print("Pass")
} else {
    print("Fail")
}
```
